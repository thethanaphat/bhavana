# ภาวนา

Mobile-first PWA สำหรับนั่งสมาธิ เดินจงกรม และสวดมนต์

**ที่มาของชื่อ:** ภาวนา (บาลี _bhāvanā_) แปลว่า "การทำให้เจริญ" ไม่ใช่แค่การนั่งสมาธิ เป็นคำที่ครอบคลุมทั้งสามกิจกรรมในแอปนี้ และตรงกับสิ่งที่แอปทำคือสะสมและแสดงการฝึกที่เติบโตขึ้นข้ามวันข้ามเดือน ชื่อ repo และ URL ใช้รูปโรมัน `bhavana` โปรเจกต์นี้แยกจาก `IC Summary Web & Ebook` โดยสิ้นเชิง ไม่มี login, backend, โฆษณา หรือ analytics

## สถานะ

**ใช้งานจริงแล้วที่ https://thethanaphat.github.io/bhavana/** — เปิดใน Safari บน iPhone แล้วเพิ่มไปยังหน้าจอโฮมเพื่อใช้เหมือนแอปจริง

ใช้งานจริงมาแล้ว 2 สัปดาห์ (ถึง 2 ต.ค. 2569) ระฆังดังครบแม้ล็อกจอ ไม่พบปัญหา

| | ทำอะไรได้ |
|---|---|
| ฝึก | นั่งสมาธิ/เดินจงกรม จับเวลา พัก/ต่อ ระฆังเริ่ม·ระหว่างฝึก·จบ เสียงพื้นหลังฝน/ทำนองบรรเลง |
| บทสวด | อ่าน 3 บทหลัก + บทส่วนตัว บันทึกการสวด (รอบ/นาที) |
| บันทึก | สถิติ วัน/สัปดาห์/เดือน/ทั้งหมด **เลื่อนดูย้อนหลังได้ มีกราฟแท่ง** · **บันทึกย้อนหลัง** สำหรับวันที่ฝึกโดยไม่ได้จับเวลา · ลบรายการ |
| ตั้งค่า | ส่งออก/นำเข้า JSON, ล้างประวัติ |

**Milestone 7 (บันทึกย้อนหลัง + สถิติแบบเลื่อนดู) เสร็จในโค้ดแล้ว รอ push ขึ้น production และลองบน iPhone จริง** รายละเอียดเหตุผลใน [ARCHITECTURE.md](ARCHITECTURE.md)

**ยังไม่ได้ทดสอบ:** สายเข้าแทรกระหว่างฝึก และ Low Power Mode

**ไอเดียถัดไป (ยังไม่ทำ):** ระฆังและเพลงบรรเลงให้เลือกมากขึ้น

## รันบนเครื่อง

ต้องมี Node.js 20.19 ขึ้นไป (หรือ 22.12 ขึ้นไป) และ npm จากนั้นรันในโฟลเดอร์นี้:

บน Mac ให้ดับเบิลคลิก `เปิดแอป.command` แล้วรอหน้าแอปเปิดในเบราว์เซอร์ที่ `http://127.0.0.1:5173/` ต้องเปิดหน้าต่าง Terminal ค้างไว้ขณะใช้งาน **Ctrl+C ใน Terminal ใช้หยุดเซิร์ฟเวอร์เมื่อเลิกดูแอป ไม่มีหน้าใหม่เปิดขึ้นหลังจากกด**

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ `http://localhost:5173`) ในเบราว์เซอร์บนเครื่อง

ตรวจและสร้าง production build:

```bash
npm run check
npm run build
npm run preview
```

ผล build อยู่ใน `dist/`. Service worker จะลงทะเบียนเฉพาะ production build เพื่อไม่ให้ cache รบกวนการพัฒนา. การลอง Add to Home Screen และ offline บน iPhone ต้องเปิดผ่าน HTTPS ของ static host หรือ HTTPS tunnel; `localhost` บน Mac ไม่ใช่ `localhost` ของ iPhone

### ทดสอบจาก iPhone ผ่าน Wi-Fi วงเดียวกัน

```bash
npm run build
npm run preview -- --host
```

แล้วเปิด URL แถว Network ที่ Vite แสดง (เช่น `http://192.168.1.58:4173/`) บน iPhone ใช้ทดสอบเรื่องเสียงและการล็อกจอได้ครบ

**ข้อควรรู้: origin แบบ `http://<ip>` ไม่ใช่ secure context** จึงไม่มี `crypto.randomUUID`, service worker และ Screen Wake Lock ให้ใช้ ID ของ record สร้างผ่าน `newId()` ใน `src/data/id.ts` ซึ่งมี fallback ไว้แล้ว แต่ **การทดสอบ Add to Home Screen, offline และ wake lock ยังต้องใช้ HTTPS** (static host หรือ `cloudflared tunnel --url http://localhost:4173`)

## การ deploy

**GitHub = ทั้งแหล่งจริงของโค้ดและโฮสต์ production ผ่าน GitHub Pages · ไม่ใช้โดเมนธุรกิจ เพราะโปรเจกต์ต้องอยู่ได้แม้เจ้าของหยุดทำธุรกิจ · ไม่ใช้ Railway · Cloudflare Pages กับ R2 เป็นทางหนีเมื่อคนใช้เยอะ**

push เข้า `main` แล้ว GitHub Actions จะ `npm ci` → `npm test` → `npm run build` → ตรวจขนาดไฟล์ → ปล่อยขึ้น Pages ให้เอง ถ้า test ตกจะไม่มีอะไรขึ้นเว็บ

| | |
|---|---|
| Build command | `npm run build` |
| Output directory | `dist` |
| Node version | อ่านจาก `.node-version` (22.12.0) |
| Environment variables | ไม่มี |
| Redirect / rewrite | ไม่ต้องตั้ง เพราะใช้ hash routing |
| Base path | `./` ใช้ได้ทั้งที่รากและใต้ subpath |

รายละเอียด เหตุผล นโยบายไฟล์เสียง เพดานที่ต้องไม่ชน และวิธีย้ายไปโฮสต์อื่น อยู่ใน [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

## ข้อมูลของคุณ

เปิดเมนูตั้งค่า (ปุ่มมุมขวาบน) จะมีส่งออกเป็นไฟล์ JSON, นำเข้าจากไฟล์สำรอง และล้างประวัติทั้งหมด

**ข้อมูลผูกกับที่อยู่เว็บที่ใช้เปิดแอป** `http://192.168.1.58:4173` กับโดเมนจริงคือคนละที่เก็บข้อมูล ก่อนย้ายต้องส่งออกแล้วนำเข้ากลับ ไฟล์สำรองไม่มีบัญชีสำหรับกู้คืน เก็บไว้เอง

## โครงสร้างสำคัญ

- `content/prayers/catalog.json` — รายชื่อบทสวดเริ่มต้น 3 บทในที่เดียว
- `content/prayers/*.txt` — ข้อความบทสวดแยกจากหน้าจอ; ดูที่มาและข้อควรตรวจทานใน `content/prayers/README.md`
- `src/features/` — หน้าแยกตามกิจกรรม
- `src/data/` — model และ IndexedDB schema เวอร์ชัน 1
- `CustomPrayer` และ `ChantSession` เก็บใน IndexedDB; ประวัติการสวดจำชื่อบทไว้ ณ วันที่บันทึก แม้แก้หรือลบบทส่วนตัวภายหลัง
- `src/features/records/stats.ts` — คำนวณช่วงเวลาใน timezone ของเครื่อง; สัปดาห์เริ่มวันจันทร์; ระยะเวลานั่ง/เดินที่ข้ามเที่ยงคืนแบ่งตามช่วงฝึกจริง; เลื่อนช่วง (`shiftAnchor`) และแท่งกราฟ (`buildBuckets`)
- `src/features/records/backfill.ts` — สร้างและตรวจบันทึกย้อนหลัง (`source: 'manual'`) แยกจากหน้าจอเพื่อให้เทสต์ได้
- `public/manifest.webmanifest`, `public/sw.js` — PWA และ offline app shell
- `public/icons/` — ไอคอนสำหรับเว็บและ Home Screen
- `public/audio/bells/`, `public/audio/ambience/` — เสียงระฆังสั้นและเสียงพื้นหลังตัวอย่างที่สร้างในโปรเจกต์; `scripts/generate_audio.py` ใช้สร้างไฟล์ใหม่เมื่อจำเป็น

เสียงบทสวดเป็นไฟล์ของเจ้าของแอปที่เพิ่มเอง วาง `.m4a` ใน `public/audio/` ด้วยชื่อ `itipiso.m4a`, `bahung.m4a`, `millionaire_chant.m4a` ตาม `catalog.json`; หน้าอ่านจะแสดงเครื่องเล่นเมื่อเว็บเสิร์ฟไฟล์นั้นเป็นชนิดเสียง การเปิดเสียงไม่สร้างบันทึกการสวด

ข้อมูลการตั้งค่าและประวัติจะบันทึกใน IndexedDB ของเบราว์เซอร์เครื่องนั้น ไม่มีการส่งข้อมูลการฝึกไป server

สถิติการสวดนับครั้งและรอบตามวันที่บันทึกการสวด เวลาสวดที่ผู้ใช้กรอกเป็นเวลาโดยประมาณและไม่นำรอบไปแปลงเป็นนาที บันทึกนั่ง/เดินที่สร้างก่อน Milestone 4 ไม่มีรายละเอียดช่วงพัก หากข้ามวัน ระบบจะแบ่งเวลาโดยประมาณโดยอิงเวลาจบของบันทึกนั้น
