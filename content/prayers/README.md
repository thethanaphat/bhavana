# ที่มาข้อความบทสวด

ข้อความอยู่ในไฟล์ `.txt` แยกจาก UI เพื่อให้ตรวจและแก้ไขได้เป็นรายบท โดยมี metadata ใน `catalog.json`

- `itipiso.txt`: บทเต็มพระพุทธคุณ พระธรรมคุณ พระสังฆคุณ จบที่ “โลกัสสาติ” ตามที่เจ้าของโปรเจกต์ต้องการ เทียบกับ [เอกสารบทสวดของมหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย](https://info.mcu.ac.th/wp-content/uploads/2020/12/%E0%B8%9A%E0%B8%97%E0%B8%AA%E0%B8%A7%E0%B8%94%E0%B8%9E%E0%B8%B4%E0%B8%98%E0%B8%B5%E0%B9%80%E0%B8%88%E0%B8%A3%E0%B8%B4%E0%B8%8D%E0%B8%9E%E0%B8%A3%E0%B8%B0%E0%B8%9E%E0%B8%B8%E0%B8%97%E0%B8%98%E0%B8%A1%E0%B8%99%E0%B8%95%E0%B9%8C-%E0%B9%80%E0%B8%88%E0%B8%A3%E0%B8%B4%E0%B8%8D%E0%B8%88%E0%B8%B4%E0%B8%95%E0%B8%A0%E0%B8%B2%E0%B8%A7%E0%B8%99%E0%B8%B2-%E0%B8%97%E0%B8%B8%E0%B8%81%E0%B8%A7%E0%B8%B1%E0%B8%99%E0%B8%88%E0%B8%B1%E0%B8%99%E0%B8%97%E0%B8%A3%E0%B9%8C%E0%B9%81%E0%B8%A3%E0%B8%81%E0%B8%82%E0%B8%AD%E0%B8%87%E0%B9%80%E0%B8%94%E0%B8%B7%E0%B8%AD%E0%B8%99.pdf)
- `bahung.txt`: เทียบแปดคาถาและบทท้ายกับ [วัดจุฬามณี: พุทธชัยมงคลคาถา](https://watchulamanee.org/th/knowledge/phuttha-chaiyamongkhon-gatha) จัดบรรทัดใหม่เพื่อให้อ่านบนมือถือได้
- `millionaire-chant.txt`: ถอดเฉพาะท่อนสวดจากไฟล์ของเจ้าของโปรเจกต์ `Desktop/คาถาเงินล้าน พร้อมคำแปล และที่มา.docx`; ไม่รวมคำอธิบาย คำแปล หรือข้ออ้างเรื่องผลของคาถา

บทสวดมีหลายสำนวนและการสะกดต่างกัน ก่อนเผยแพร่ให้เจ้าของโปรเจกต์ตรวจเทียบกับบทที่ใช้สวดจริง โดยเฉพาะคาถาเงินล้านและคำลงท้ายพาหุง

ไฟล์เสียงเป็นของเจ้าของแอปเอง วางไว้ใน `public/audio/` ตามชื่อไฟล์ใน `catalog.json` เมื่อมีไฟล์ `.m4a` แอปจะแสดงตัวเล่นเสียงแบบพื้นฐาน เสียงไม่ถูก pre-cache และการฟังไม่สร้างบันทึกการสวด
