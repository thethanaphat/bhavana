เสียงที่แอปมีให้ใน Milestone 5 อยู่ใน `bells/` และ `ambience/` ทั้งหมดสร้างด้วย `scripts/generate_audio.py` ภายในโปรเจกต์นี้เอง โดยใช้ Python 3 และ ffmpeg (`python3 scripts/generate_audio.py`) ไม่มีการนำไฟล์เสียงจากแอปอื่นมาใช้ เสียงพื้นหลังยาว 48 วินาทีและเล่นวนซ้ำ; service worker เก็บล่วงหน้าเฉพาะไฟล์ระฆังสั้น เสียงฝนและเสียงบรรเลงเป็นตัวอย่างที่ต้องให้เจ้าของโปรเจกต์ฟังและเลือกอีกครั้งก่อนเผยแพร่
